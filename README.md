# おでかけしおり

## Web版

「おでかけしおり」は、以下のURLからWebアプリとしてそのまま利用できます。

https://tripproject-7539a.web.app/

ローカルで動作確認する場合は、以下の手順で起動してください。

## 起動方法

### 1. パッケージをインストール

「おでかけしおり」フォルダをターミナル（コマンドプロンプト、PowerShell等）で開き、以下のコマンドを順番に実行してください。

```bash
npm install
```

### 2. アプリを起動

```bash
npm run dev
```

### 3. ブラウザでアクセス

以下のURLをブラウザで開いてください。

http://localhost:5173/

## APIについて

APIはCloudflare Workersにデプロイ済みです。

フロントエンドはデプロイ済みのAPIへ接続するため、
Workerをローカルで起動する必要はありません。

## 必要環境

- Node.js
- npm
